# Многопоточный скрапер книг (books.toscrape.com)

Учебный проект для практики многопоточности (`threading`) и очередей (`queue.Queue`) в Python.

## Что делает
- Собирает данные о книгах (название, цена, рейтинг) с сайта books.toscrape.com
- Обрабатывает все страницы каталога параллельно, используя пул потоков
- Передаёт данные между потоками через `queue.Queue`
- Сохраняет результат в CSV/JSON (добавишь после того, как сделаешь сохранение)

## Технологии
- `requests` — HTTP-запросы
- `BeautifulSoup` — парсинг HTML
- `threading` + `queue.Queue` — параллельная обработка страниц

## Как запустить
\`\`\`bash
pip install -r requirements.txt
python main.py
\`\`\`

## Результаты замера скорости
- Синхронно: X сек
- Многопоточно (N потоков): Y сек

## Чему научился
- Работа с `threading.Thread`, `.start()`/`.join()`
- Безопасная передача данных между потоками через `queue.Queue`
- Разница между I/O-bound задачами (где потоки дают прирост) и CPU-bound
